# PocketFriend
PocketFriend is a local-first AI study companion built for the DEV Community Hacktoberfest 2026 Weekend Challenge: Build for a Friend.

- Core AI: Google Gemma running locally via Ollama
- Tech: Python, Streamlit, Ollama, Gemma, PyMuPDF, ChromaDB, sentence-transformers, SQLite
- Priority: reliable local execution on modest hardware (~8GB RAM)
